# Security and industrial use

Report a suspected vulnerability in Visual Toolkit through [GitHub's private vulnerability report](https://github.com/Grindstone-Systems/visual-toolkit/security/advisories/new). Include the affected version or URL, impact and safe reproduction steps. Do not post exploit details, credentials or plant data in a public issue, and do not test against a production plant system. Private vulnerability reporting is enabled for this repository.

Visual Toolkit generates visual assets and example HMI layouts. It does not implement a safety function, alarm system, interlock or industrial controller. Verify exported assets and any host integration under your site's engineering, OT security, accessibility and change-control procedures before production use. The repository's Apache-2.0 license governs the code; it does not itself promise support, security updates, or suitability for a particular installation. Supported versions and a response or patch time have not been established.

Use public issues for ordinary bugs or feature requests that contain no sensitive security information. Grindstone Systems may publish a GitHub security advisory when a confirmed issue warrants one.
